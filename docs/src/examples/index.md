# Examples

A gallery of examples of the method of Lagrangian descriptors, from simple systems with known phase portraits to chaotic and stochastic ones. Each example sets up the problem, computes the Lagrangian descriptors, and discusses the picture.

| Example | Features |
|:------- |:-------- |
| [Saddle point](saddle.md) | linear system; stable and unstable manifolds |
| [Pendulum](pendulum.md) | conservative system; separatrices between oscillations and rotations |
| [Van der Pol oscillator](vanderpol.md) | limit cycle; solutions diverging backward in time |
| [Double gyre](doublegyre.md) | time-dependent fluid flow; lobes and transport |
| [Lorenz system](lorenz.md) | three-dimensional chaotic system; two-dimensional slices of initial conditions |
| [Double pendulum](doublependulum.md) | four-dimensional chaotic Hamiltonian system |
| [Stochastic Duffing equation](stochastic_duffing.md) | stochastic differential equation; a single realization and the mean over realizations |

The periodically forced Duffing equation, a random Duffing equation and a Duffing equation with multiplicative noise are treated step by step in the tutorials on [ODEs](../tutorial_ODEs.md), [RODEs](../tutorial_RODEs.md) and [SDEs](../tutorial_SDEs.md). For the choice of the infinitesimal descriptor, the time window and the grid of initial conditions, see [Choosing the descriptor and the time window](../choosing.md).
