# References

The method of Lagrangian descriptors was introduced by [MadridMancho2009](@citet) and developed by [ManchoEtAl2013](@citet), with a theoretical framework given by [LopesinoEtAl2017](@citet) and an extension to stochastic differential equations by [BalibreaIniestaEtAl2016](@citet). For an introduction to the method, see [WigginsGarciaGarrido2022](@citet), and for a comprehensive account, with many examples, see the online book by [AgaoglouEtAl2020](@citet). Answers to frequently asked questions about the method are collected by [Mancho2016FAQ](@citet).
